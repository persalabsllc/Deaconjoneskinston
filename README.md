# Deacon Jones Kinston — An Independent Review

Static, responsive independent commentary website. It is unaffiliated with the dealership or Kia.

## Files

- `dist/index.html`: page content, metadata, and embedded favicon.
- `dist/styles.css`: responsive styles, keyboard focus, reduced-motion, and print rules.
- `.openai/hosting.json`: Sites project identity and public asset directory.
- `vercel.json`: optional static deployment configuration.

No dependencies, build step, analytics, forms, or client-side JavaScript are required. Serve `dist/` as the public directory.

## Editorial scope

Content presents independent commentary and questions for applicants and buyers. It does not identify a writer, source, employer relationship, or job title. Do not add identifying names, initials, biographies, employment details, contact details, or personal account information to site content or metadata.

The buyer guidance is sourced to the Federal Trade Commission. The quotation of the dealership’s stated values links to its own website. Company names identify the subject; the design does not use official logos or claim affiliation.

Keep statements accurate. Do not invent incidents, evidence, or testimonials.

## Domain

Use a domain that does not identify an individual. Check the hostname as well as visible content and metadata before making the website public.
